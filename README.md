# 📈 Multi-Page Data Visualization Dashboard

An interactive web application built with **Streamlit**, **Pandas**, and **Matplotlib** to explore and analyze diverse datasets ranging from weather patterns to customer demographics.

## ✨ Features

The application is structured into three distinct modules accessible via the sidebar:

* **🌡️ Temperature Analysis:** A time-series visualization tracking maximum, minimum, and average weekly temperatures.
* **🏠 Home Rent Analysis:** Explores the relationship between property `area` and `price` through side-by-side line and scatter plots.
* **👥 Customer Demographics:** * Dynamic distribution of **Gender** and **Profession** based on user-uploaded data.
    * Visual breakdown of daily activities via interactive pie charts.
* **📂 Dynamic File Upload:** Includes a CSV file uploader to allow real-time analysis of custom demographic data.
